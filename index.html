      Aide

      • Pour modifier votre fiche : touchez « Réglages », puis « Modifier ma fiche ».
      • Pour écouter votre fiche : touchez « Écouter », en haut de l’écran.
      • Pour préparer un appel : touchez « Préparer un appel », puis la raison de votre appel.
      • Pour sauvegarder vos données : touchez « Réglages », puis « Mes données », puis « Sauvegarder dans un fichier ».
      • Pour installer l’application : ouvrez-la dans Chrome, touchez les trois points en haut à droite, puis « Ajouter à l’écran d’accueil ».
